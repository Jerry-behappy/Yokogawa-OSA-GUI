# Python 版

使用 Python/Tkinter 与 Matplotlib 重写的 Yokogawa AQ6370D 光谱仪控制界面，通过系统 Socket 通信，无需 VISA 或 pyserial。

## Windows 启动

1. 安装 Python 3.10 或以上版本，并添加到 PATH。
2. 双击 `安装依赖.bat`，在当前文件夹创建 `.venv` 并安装依赖。
3. 双击 `启动Python版.bat`。

也可在终端运行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe yokogawa_OSA_GUI.py
```

Linux/macOS 可使用相同源码，启动解释器需安装 Tk 支持。

## 连接与操作

在仪器中选择 `SYSTEM → Remote Interface → Net(Socket)`。默认 IP 为 `192.168.3.63`，端口 `10001`，超时 5 秒；根据实际网络修改后点击连接。使用匿名账号与空格密码认证，不保存任何密码。

设置中心波长、跨度、分辨率、灵敏度、点数以及三条 Trace 的显示和 WRITE/FIX 属性；空闲时修改参数自动下发，采集中锁定仪器参数。扫描起止波长须在 600–1700 nm 内。

点击“单次采集”或“开始连续采集”。每一轮依次执行参数设置、SINGLE 扫描、等待 `*OPC?`、读回配置、读取所有选择的 Trace、校验数据和绘图；完整绘制后才开始下一轮。“停止连续采集”会等待当前轮完成，再恢复仪器 REPEAT 扫描；单次采集完成后也恢复 REPEAT。断开连接可取消当前等待。

勾选 `TRC = TRA − TRB (LOG)` 后，数学计算由仪器执行，Python 读回结果和表达式。数学 TRC 使用 `Loss (dB)`，其他曲线使用 `Power (dBm)`。FIX 曲线按自身点数校验，因此它可以和当前扫描的点数不同。

三个标签页分别显示 TRA/TRB/TRC，底部可选择自动或手动坐标范围，绘图区工具栏提供缩放、平移和图片保存。

## 数据保存

选择目录、基础名称、Trace 和 MAT/CSV 格式。文件名为 `基础名称_Trace`，重名自动追加 `_1`、`_2`。

MAT 保留 `XDataNm`、`XDataMeters`、`YData` 等数组及采集元数据，可在 MATLAB 中直接 `load`。Python 导出的 `AcquiredAt` 为文本时间戳；MATLAB 原版对应字段为 MATLAB datetime。

CSV 使用 UTF-8 编码，开头为 `#` 元数据行，空行之后为 `Wavelength_nm` 与 `Power_dBm` 或 `Loss_dB` 两列。选中 Res/SENS 时包含相应分辨率/灵敏度元数据。

保存使用已完成采集的配置快照。扫描中心/跨度为该轮仪器读回值；FIX 的实际波长以其 `XDataNm` 为准。收到损坏、缺失或点数不一致的响应时，最多尝试三次完整 X/Y 读取；网络超时会断开连接，保留上一轮有效帧。

Windows 设置保存在 `%LOCALAPPDATA%\YokogawaOSAGUI\settings.json`，启动错误日志在同一目录。其他系统默认使用 `~/.config/YokogawaOSAGUI/`。

## 离线验证

```powershell
python yokogawa_OSA_GUI.py --self-test
python yokogawa_OSA_GUI.py --gui-smoke-test
```

测试只使用模拟仪器和本机回环网络，不访问实物设备。GUI 测试覆盖五轮串行采集、停止恢复 REPEAT、失败保留有效帧、坐标范围以及断开和关闭。
