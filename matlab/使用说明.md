# MATLAB 版

Yokogawa AQ6370D 光谱仪的以太网控制界面。

## 启动

1. 使用 MATLAB R2023a 或更新版本；程序使用 `uifigure`、`uigridlayout`、`tcpclient`。
2. 将 MATLAB 当前文件夹切换到本目录。
3. 在命令窗口运行：

```matlab
yokogawa_OSA_GUI
```

## 仪器连接与采集

在仪器 `SYSTEM → Remote Interface` 中选择 `Net(Socket)`，将电脑和仪器接入可通信的网络。程序默认 IP 为 `192.168.3.63`，端口为 `10001`，超时为 5 秒；请按仪器实际配置修改。

连接后，设置中心波长、跨度、分辨率、灵敏度和点数，再选择 TRA/TRB/TRC，执行单次或连续采集。WRITE 更新曲线，FIX 保留曲线；TRC 可设置为仪器执行的 `A-B(LOG)`，其纵轴显示 `Loss (dB)`。

单次采集完成，或停止软件连续采集并完成最后一轮后，仪器恢复 REPEAT 扫描。停止软件采集后，仪器仍会自行扫描。

采集数据在窗口内的三个 Trace 标签页显示，可设 X/Y 轴范围。选择保存目录、基础名称、Trace 和 MAT/CSV 格式后点击保存；文件重名时自动追加 `_1`、`_2`。设置由 MATLAB 偏好系统保存。

保存目录的“选择...”会在保存面板内打开目录浏览器。选中子目录后点击“打开子目录”，用“上一级”返回；也可在顶部输入完整路径，按回车跳转。点击“选择当前目录”确认，或点击“取消”保留原目录。浏览时不会弹出系统目录对话框。

该目录保留提供的 MATLAB 原始程序。默认参数是连接示例；扫描范围应遵循 AQ6370D 的实际量程。
